"SIGN-VOICE-AI"

Sistema de apoyo a la comunicación mediante inteligencia artificial y lengua de señas.

Descripción del proyecto:
SIGN-VOICE-AI es un proyecto de Desarrollo de Software que busca facilitar la comunicación entre personas sordas y oyentes mediante tecnologías de reconocimiento de manos e inteligencia artificial.
El sistema está orientado al reconocimiento de señas captadas mediante una cámara y a su interpretación en texto y voz, según las funcionalidades implementadas.

Objetivo general:
Desarrollar una aplicación que utilice el reconocimiento de manos y la inteligencia artificial para apoyar la comunicación accesible entre personas sordas y oyentes.

Objetivos específicos:
- Capturar los movimientos de las manos mediante una cámara.
- Identificar puntos de referencia para analizar las señas.
- Facilitar el reconocimiento de señas mediante inteligencia artificial.
- Presentar los resultados en texto y voz, según las funciones disponibles.
- Promover la inclusión mediante herramientas tecnológicas.

Funcionalidades:
- Acceso a la cámara del dispositivo.
- Detección de puntos de referencia de las manos.
- Reconocimiento de señas mediante inteligencia artificial.
- Presentación de resultados en texto.
- Conversión de texto a voz, si está implementada.
- Captura y almacenamiento de muestras de señas, si está disponible.
- Interfaz adaptable a dispositivos compatibles.

Tecnologías:
El proyecto contempla tecnologías para el desarrollo de la interfaz, el reconocimiento de manos, el procesamiento mediante inteligencia artificial y el almacenamiento de información.
Entre las herramientas consideradas se encuentran HTML, CSS, JavaScript, MediaPipe Hands y una base de datos, de acuerdo con la implementación final.

Requisitos del sistema:
- Computadora o dispositivo compatible.
- Navegador web actualizado.
- Cámara funcional.
- Permisos para acceder a la cámara.
- Conexión a Internet cuando las funciones lo requieran.

Instalación y ejecución:
Para utilizar la aplicación, se deben obtener los archivos del proyecto desde el repositorio y seguir las instrucciones de instalación correspondientes a las tecnologías utilizadas.
Si el sistema requiere servicios adicionales, como una API, un modelo de inteligencia artificial o una base de datos(SQL,MYSQL,SUPABSE), estos deberán configurarse antes de ejecutar la aplicación.

Base de datos:
La documentación de la base de datos incluirá su diseño, las entidades, las relaciones y el script SQL correspondiente, de acuerdo con la implementación del sistema.

Pruebas:
Se realizarán pruebas para verificar el acceso a la cámara, la detección de manos, la captura de muestras, el reconocimiento de señas y la presentación de resultados.
Los resultados se documentarán conforme se completen las pruebas del sistema.

Privacidad y uso responsable:
La información capturada debe manejarse respetando la privacidad de las personas. El reconocimiento automático puede presentar errores, por lo que la aplicación debe utilizarse como una herramienta de apoyo a la comunicación.
